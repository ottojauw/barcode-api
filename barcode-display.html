📖 Usage Guide

Without Parameters (Default)

Simply open the page without any parameters to see a default barcode:

barcode-display.html

This will display a CODE128 barcode with value "123456789"

With Query Parameters

Pass parameters in the URL to customize the barcode:

barcode-display.html?value=YOUR_VALUE&format=CODE128
value The data to encode (required) value=123456789
format Barcode type (optional, default: CODE128) format=EAN13
width Bar width (optional, default: 2) width=3
height Barcode height in pixels (optional, default: 100) height=150

Full Example URLs

barcode-display.html?value=123456789 barcode-display.html?value=5901234123457&format=EAN13 barcode-display.html?value=PRODUCT123&format=CODE39&width=3&height=120

Embedding in Your Website

Use an iframe to embed barcodes in your website:

<iframe src="barcode-display.html?value=123456789&format=CODE128" width="400" height="300" frameborder="0"></iframe>

API Endpoint

For direct API access (returns JSON with base64 image):

https://barcode-api-two.vercel.app/api/barcode?value=123456789

Perfect for use in applications, scripts, or automated systems
