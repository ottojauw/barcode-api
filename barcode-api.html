📊 Barcode Generation API

API Endpoint

Generate barcodes by making GET requests to:

GET /?value=123456789&format=CODE128&width=2&height=100

Query Parameters

Parameter Description Default
value The data to encode (required) -
format Barcode format (CODE128, EAN13, UPC, CODE39, etc.) CODE128
width Width of individual bars 2
height Height of barcode in pixels 100
displayValue Show text below barcode (true/false) true

Response Format

{ "success": true, "data": "data:image/png;base64,iVBORw0KGgoAAAANS...", "format": "CODE128", "value": "123456789" }

Usage Examples

            
            
JavaScript (Fetch API)

            
fetch('/?value=123456789&format=CODE128&width=2&height=100')
  .then(response => response.json())
  .then(data => {
    console.log('Base64 Image:', data.data);
    // Use the base64 image
    const img = document.createElement('img');
    img.src = data.data;
    document.body.appendChild(img);
  });


            
Python

            
import requests
import base64

response = requests.get(
    'http://localhost:8000/',
    params={
        'value': '123456789',
        'format': 'CODE128',
        'width': 2,
        'height': 100
    }
)

data = response.json()
base64_image = data['data']
print(base64_image)
